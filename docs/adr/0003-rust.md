# Rust (gtk4-rs + vte4-rs) para la app y el daemon

Escribimos la app y el daemon en Rust con gtk4-rs y vte4-rs. El daemon maneja muchas pseudo-terminales concurrentes y tiene que ser robusto. Rust da tipado, un solo binario sin runtime que empaquetar, y buen soporte de PTYs y async. Descartamos Python (PyGObject) porque el daemon quedaba frágil y había que empaquetar el runtime, y C/Vala porque se programa más lento.
